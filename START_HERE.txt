Jet Set Radio Future recomp

Full instructions, for first-time users too: README.md (open it with a text
editor, or read it on the GitHub page).

Short version:
  1. get jsrf_launcher from the Releases page and put it in an empty folder
  2. start it, and copy your game files (default.xbe and the rest) into the
     jsrf folder it makes
  3. Update -> Download, then Play -> Build
  4. PLAY
